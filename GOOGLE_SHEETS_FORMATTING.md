# Форматирование текста в Google Sheets для Telegram бота

## Поддерживаемое форматирование

Бот поддерживает HTML форматирование в описаниях курсов. Вы можете использовать следующие теги в колонке `description`:

### Жирный текст
```
<b>жирный текст</b>
```
или
```
<strong>жирный текст</strong>
```

### Курсив
```
<i>курсив</i>
```
или
```
<em>курсив</em>
```

### Подчеркнутый текст
```
<u>подчеркнутый</u>
```

### Зачеркнутый текст
```
<s>зачеркнутый</s>
```
или
```
<del>зачеркнутый</del>
```

### Моноширинный текст (код)
```
<code>код</code>
```

### Блок кода
```
<pre>блок кода</pre>
```

### Ссылки
```
<a href="https://example.com">текст ссылки</a>
```

## Списки

### Маркированные списки
Используйте дефис с пробелом в начале строки:
```
- Первый пункт
- Второй пункт
- Третий пункт
```

### Нумерованные списки
Используйте номер с точкой и пробелом:
```
1. Первый пункт
2. Второй пункт
3. Третий пункт
```

## Абзацы

Просто оставьте пустую строку между абзацами:
```
Первый абзац текста.

Второй абзац текста.
```

## Пример полного описания

```
<b>GlamGlow</b>

В этом уроке мы разберем технику, которая дает тот самый дорогой глам-эффект.

Мы шаг за шагом пройдем:
- технику вытянутой стрелки с плавным подъемом
- правильный уход для создания светящейся базы
- моделирование лица мягкими бликами
- расстановку глам-акцентов

Этот урок - про <b>сексуальность</b>, <i>женственность</i> и уверенность.
```

## Важные замечания

1. **Специальные символы**: Символы `<`, `>`, `&` будут автоматически экранированы, если они не являются частью валидных HTML тегов.

2. **Название курса**: HTML теги в названии курса (колонка `name`) будут удалены, так как название используется в кнопках, которые не поддерживают форматирование.

3. **Переносы строк**: Все переносы строк сохраняются, так что вы можете использовать многострочный текст.

4. **Комбинирование тегов**: Можно комбинировать теги, например:
   ```
   <b><i>жирный курсив</i></b>
   ```

## Проверка форматирования

После заполнения описания в Google Sheets, проверьте отображение в боте, открыв курс в каталоге. Форматирование должно отображаться корректно.
