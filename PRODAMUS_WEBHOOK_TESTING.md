> ℹ️ Напоминаем, что бот реагирует только на `Result URL`. Остальные адреса служат исключительно для редиректа пользователя и могут быть отключены.

## Настройка тестового вебхука через webhook.site

### Шаг 1: Добавьте URL в .env файл

Добавьте следующую строку в ваш `.env` файл:

```env
PRODAMUS_TEST_WEBHOOK_URL=https://webhook.site/fbb902fc-f9df-424d-996f-1eb64f15714d
```

Этот URL будет использоваться для тестирования - все данные вебхуков будут дублироваться на webhook.site для просмотра.

   - **Пароль:** `aNWQhbWJ46EH`

#### 2.2 Настройка адресов (Success/Fail URLs)

1. В настройках платежной формы найдите раздел **"Настройка адресов"** или **"URL для редиректа"**
2. Установите следующие URL:

   **Success URL (URL успешной оплаты):**
   ```
   https://webhook.site/fbb902fc-f9df-424d-996f-1eb64f15714d?type=success
   ```

   - Prodamus отправляет данные через POST или GET запросы
   - Это основной URL для обработки платежей - именно здесь бот получает информацию об успешной оплате

### Шаг 3: Тестирование

1. **Запустите бота** с обновленным `.env` файлом
2. **Сделайте тестовый платеж** через бота:
   - Откройте карточку курса
   - Нажмите "Купить (Prodamus)"
   - Введите email (если запросит)
   - Перейдите по ссылке на оплату
   - Заполните форму и оплатите

3. **Проверьте webhook.site**:
   - Откройте `https://webhook.site/#!/fbb902fc-f9df-424d-996f-1eb64f15714d`
   - Вы увидите все запросы от Prodamus:
     - **Result URL** - уведомление о статусе платежа (самое важное!)
     - **Success URL** - редирект после успешной оплаты
     - **Fail URL** - редирект после неуспешной оплаты

4. **Проверьте логи бота**:
   - Должны быть сообщения вида:
     ```
     [Prodamus Result] Received notification: {...}
     [Prodamus Test] Forwarded result data to test webhook
     [Prodamus Result] Successfully processed payment for order ...
     ```

### Что проверять в webhook.site

#### Result URL (самый важный!)
Должен содержать данные о платеже:
- `order` или `order_id` - номер заказа
- `sum` или `amount` - сумма платежа
- `status` - статус платежа (`success`, `paid`, `successful` для успешных)
- `signature` - подпись для проверки (если включена)

#### Success URL
Должен содержать данные о редиректе после успешной оплаты (обычно те же параметры, что и Result URL)

#### Fail URL
Должен содержать данные о редиректе после неуспешной оплаты

### Формат данных от Prodamus

Prodamus может отправлять данные в разных форматах:

**GET запрос:**
```
https://webhook.site/...?order=PROD-123&sum=100.00&status=success&signature=abc123
```

**POST запрос (form-data):**
```
order=PROD-123
sum=100.00
status=success
signature=abc123
```

**POST запрос (JSON):**
```json
{
  "order": "PROD-123",
  "sum": "100.00",
  "status": "success",
  "signature": "abc123"
}
```

Бот обрабатывает все эти форматы автоматически.

### Устранение проблем

#### Вебхуки не приходят на webhook.site
- Проверьте, что URL правильно указан в админке Prodamus
- Убедитесь, что URL использует HTTPS
- Проверьте, что вы сохранили настройки в админке Prodamus

#### Бот не обрабатывает платежи
- Проверьте логи бота на наличие ошибок
- Убедитесь, что `PRODAMUS_SECRET_KEY` правильный
- Проверьте, что `order_id` в базе данных совпадает с `order` из вебхука

#### Подпись не проходит проверку
- Убедитесь, что секретный ключ правильный
- Проверьте, что в админке Prodamus включена проверка подписи (если используется)

### После тестирования

Когда тестирование завершено, можно:
1. Убрать `PRODAMUS_TEST_WEBHOOK_URL` из `.env` (или оставить для отладки)
2. Настроить реальные URL для продакшена:
   - Success URL: `https://yourdomain.com/prodamus/success`
   - Fail URL: `https://yourdomain.com/prodamus/fail`
   - Result URL: `https://yourdomain.com/prodamus/result`
