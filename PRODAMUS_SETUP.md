# Инструкция по настройке Prodamus

## Обзор

Интеграция Prodamus позволяет принимать платежи через прямые ссылки на оплату. После успешной оплаты пользователь автоматически получает доступ к курсу.

> ℹ️ Начиная с текущей версии бота мы используем только `Result URL`. `Success` и `Fail` можно оставить пустыми или направить на статическую страницу с сообщением для клиента.

## Шаг 1: Настройка в личном кабинете Prodamus

### 1.1 Авторизация на платежной странице

1. Перейдите на тестовую платежную страницу: `https://testwork1.payform.ru/?old_auth=1`
2. Внизу страницы нажмите на серый замочек 🔒
3. Авторизуйтесь с тестовыми данными:
   - **Логин:** `tester@prodamus.ru`
   - **Пароль:** `aNWQhbWJ46EH`

### 1.2 Настройка адресов (Success/Fail URLs)

> Эти адреса нужны только для отображения сообщения пользователю после оплаты. Боту они не требуются, поэтому шаг можно пропустить, если редирект не нужен.

1. В настройках платежной формы найдите раздел **"Настройка адресов"**
2. Установите следующие URL (замените `YOUR_DOMAIN` на ваш домен):

   **Success URL:**
   ```
   https://YOUR_DOMAIN/prodamus/success
   ```

   **Fail URL:**
   ```
   https://YOUR_DOMAIN/prodamus/fail
   ```

   **Примеры:**
   - **PythonAnywhere:** `https://yourusername.pythonanywhere.com/prodamus/success`
   - **Локальный тест (ngrok):** `https://your-ngrok-url.ngrok.io/prodamus/success`
   - **Свой сервер:** `https://yourdomain.com/prodamus/success`

   **Важно:** Все URL должны использовать HTTPS и быть доступны из интернета!

3. Нажмите **"Сохранить"**

### 1.3 Настройка уведомлений (Result URL)

1. В разделе **"Настройка уведомлений"** найдите поле **"URL адреса для уведомлений"**
2. Добавьте URL для уведомлений о платежах:

   **Result URL:**
   ```
   https://YOUR_DOMAIN/prodamus/result
   ```

   **Примеры:**
   - **PythonAnywhere:** `https://yourusername.pythonanywhere.com/prodamus/result`
   - **Локальный тест (ngrok):** `https://your-ngrok-url.ngrok.io/prodamus/result`
   - **Свой сервер:** `https://yourdomain.com/prodamus/result`

   **Важно:** 
   - Этот URL используется Prodamus для отправки уведомлений о статусе платежа
   - URL должен быть доступен из интернета по HTTPS
   - Бот автоматически обработает уведомление и выдаст доступ пользователю

3. Нажмите **"Сохранить"**

### 1.4 Получение секретного ключа

1. В настройках найдите раздел **"Секретный ключ"**
2. Скопируйте секретный ключ (длинная строка из букв и цифр)
3. Сохраните его - он понадобится для настройки бота

   **Пример секретного ключа:**
   ```
   1af49e71d4e9842984e29e0488ba71705486054a8aa2a56b782e73667e2d14c7
   ```

### 1.5 Настройка режима работы формы

1. В разделе **"Настройка формы"** → **"Режим работы формы"**
2. Для тестирования выберите: **"Демо-режим без приёма оплаты"**
3. Для продакшена выберите: **"Режим приёма оплаты"**
4. Опционально: включите **"Оплата только по прямой ссылке"** (рекомендуется)

### 1.6 Настройка кассы (опционально)

Если вы используете собственную онлайн-кассу:

1. В разделе **"Настройка кассы Продамус"**
2. Включите **"Самостоятельное пробитие чеков"**
3. Настройте параметры кассы согласно вашим требованиям

## Шаг 2: Настройка переменных окружения

Добавьте следующие переменные в ваш `.env` файл:

```env
# Prodamus Integration
ENABLE_PRODAMUS=True
PRODAMUS_TEST_MODE=True
PRODAMUS_PAYFORM_URL=testwork1.payform.ru
PRODAMUS_SECRET_KEY=1af49e71d4e9842984e29e0488ba71705486054a8aa2a56b782e73667e2d14c7
PRODAMUS_SYSTEM_ID=
```

### Описание переменных:

- **ENABLE_PRODAMUS** — включить/выключить кнопку Prodamus в боте (`True`/`False`)
- **PRODAMUS_TEST_MODE** — тестовый режим (`True` для тестирования, `False` для продакшена)
- **PRODAMUS_PAYFORM_URL** — домен платежной формы:
  - Тест: `testwork1.payform.ru`
  - Продакшен: ваш продакшен домен (например, `yourdomain.payform.ru`)
- **PRODAMUS_SECRET_KEY** — секретный ключ из личного кабинета Prodamus
- **PRODAMUS_SYSTEM_ID** — системный ID (если требуется, обычно оставляйте пустым)

## Шаг 3: Проверка работы

### 3.1 Локальное тестирование

1. Убедитесь, что все переменные в `.env` заполнены
2. Запустите бота: `python main.py`
3. Откройте карточку курса в боте
4. Должна появиться кнопка **"Купить (Prodamus)"** рядом с кнопкой ЮKassa

### 3.2 Тестовая оплата

1. Нажмите на кнопку **"Купить (Prodamus)"**
2. Бот отправит ссылку на оплату
3. Перейдите по ссылке
4. Заполните тестовую форму оплаты
5. После оплаты проверьте:
   - Пользователь получил сообщение об успешной оплате
   - Пользователь получил доступ к каналу курса
   - Админы получили уведомление о платеже

### 3.3 Проверка логов

В логах бота вы должны видеть:

```
[Prodamus TEST MODE] Payment request from user 123456 for course 1
[Prodamus] Generated payment URL (test mode): https://testwork1.payform.ru/?old_auth=1&order=...
[Prodamus Result] Received notification: {...}
[Prodamus Result] Successfully processed payment for order ...
```

## Шаг 4: Переход в продакшен

### 4.1 Настройка продакшен аккаунта

1. Получите продакшен аккаунт в Prodamus
2. Получите продакшен домен платежной формы
3. Получите продакшен секретный ключ

### 4.2 Обновление переменных окружения

Измените в `.env`:

```env
PRODAMUS_TEST_MODE=False
PRODAMUS_PAYFORM_URL=your_production_domain.payform.ru
PRODAMUS_SECRET_KEY=your_production_secret_key
```

### 4.3 Обновление URL в Prodamus

1. В продакшен аккаунте Prodamus обновите:
   - Success URL
   - Fail URL
   - Result URL (URL для уведомлений)
2. Убедитесь, что все URL используют HTTPS
3. Переключите режим формы на **"Режим приёма оплаты"**

## Шаг 5: Устранение проблем

### Кнопка Prodamus не появляется

- Проверьте, что `ENABLE_PRODAMUS=True` в `.env`
- Проверьте, что `PRODAMUS_SECRET_KEY` заполнен и не пустой
- Перезапустите бота

### Ошибка при создании ссылки на оплату

- Проверьте логи бота на наличие ошибок
- Убедитесь, что `PRODAMUS_PAYFORM_URL` указан правильно
- Проверьте, что все переменные в `.env` заполнены

### Платеж не обрабатывается

- Проверьте, что Result URL правильно настроен в Prodamus
- Проверьте, что URL доступен из интернета (HTTPS)
- Проверьте логи бота на наличие ошибок обработки
- Убедитесь, что секретный ключ правильный

### Пользователь не получает доступ после оплаты

- Проверьте логи бота - должно быть сообщение об успешной обработке платежа
- Проверьте, что курс существует в Google Sheets
- Проверьте, что у бота есть права администратора в канале курса
- Проверьте, что канал указан правильно в Google Sheets

## Дополнительная информация

### Структура URL для оплаты

Бот генерирует URL следующего формата:

```
https://PRODAMUS_PAYFORM_URL/?old_auth=1&order=USER_ID_COURSE_ID_TIMESTAMP&sum=PRICE&description=DESCRIPTION
```

### Формат данных webhook

Prodamus отправляет на Result URL следующие данные:

- `order` — номер заказа
- `sum` — сумма оплаты
- `status` — статус платежа (`success`, `paid`, `successful` для успешных)
- `signature` — подпись для проверки (если включена)

### Безопасность

- Секретный ключ используется для проверки подлинности webhook'ов
- Все URL должны использовать HTTPS в продакшене
- Не храните секретный ключ в коде, используйте `.env` файл
- Файл `.env` должен быть в `.gitignore`
