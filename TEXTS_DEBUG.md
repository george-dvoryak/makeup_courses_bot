# Отладка загрузки текстов

## Проблема
Тексты загружаются в тестовом скрипте, но не используются в сообщениях бота.

## Что было исправлено

1. **Добавлено детальное логирование** в `get_text_value()` и `_get_texts_for_bot()`:
   - Показывает, какой бот используется
   - Показывает, какие ключи ищутся
   - Показывает, какие ключи доступны
   - Показывает, используется ли кэш или загружаются новые данные

2. **Улучшен поиск ключей** - теперь нечувствителен к:
   - Регистру (greeting_text = Greeting Text = GREETING_TEXT)
   - Пробелам и подчеркиваниям (greeting_text = greeting text = greeting-text)

3. **Добавлена предзагрузка текстов** при старте приложения

## Как проверить

1. **Проверьте логи при старте приложения:**
   ```
   [2025-XX-XX] Preloading texts for all bots...
   [2025-XX-XX] Preloaded X texts for bot1
   [2025-XX-XX] Preloaded Y texts for bot2
   ```

2. **Отправьте сообщение боту и проверьте логи:**
   ```
   [Texts] get_text_value called: key='greeting_text', bot='bot1'
   [Texts] Loading texts for bot: bot1
   [Texts] Loaded X text entries for bot1
   [Texts] Sample keys: ['greeting_text', 'catalog_intro', ...]
   [Texts] Found value for 'greeting_text': Привет!...
   ```

3. **Если ключ не найден, вы увидите:**
   ```
   [Texts] Key 'greeting_text' not found in texts (available keys: [...])
   ```

## Возможные проблемы

1. **Ключи в таблице не совпадают с кодом:**
   - Проверьте точные названия ключей в таблице
   - Убедитесь, что нет лишних пробелов
   - Ключи должны быть в первой колонке, значения - во второй

2. **Таблица не загружается:**
   - Проверьте `GSHEET_ID` для каждого бота
   - Проверьте название вкладки `GSHEET_TEXTS_NAME` (обычно "Texts")
   - Убедитесь, что таблица публичная (если `GOOGLE_SHEETS_USE_API=False`)

3. **Контекст бота не устанавливается:**
   - Проверьте логи - должен быть правильный `bot='bot1'` или `bot='bot2'`
   - Если контекст неправильный, тексты будут загружаться для другого бота

## Стандартные ключи, используемые в коде:

- `greeting_text` - приветствие при /start
- `catalog_intro` - заголовок каталога
- `catalog_empty` - сообщение, если каталог пуст
- `catalog_error` - сообщение об ошибке загрузки каталога
- `support_text` - текст поддержки
- `no_active_subscriptions` - сообщение, если нет активных подписок
- `active_subscriptions_header` - заголовок списка активных подписок
- `purchase_success_message` - сообщение об успешной оплате

## Формат таблицы Texts:

| Ключ | Значение |
|------|----------|
| greeting_text | Привет! Я помогу выбрать и оплатить курс. |
| catalog_intro | 📚 Каталог курсов\nВыберите интересующий курс: |
| ... | ... |

**Важно:** Первая колонка - ключ, вторая - значение. Первая строка может быть заголовком (key/ключ/name/название).
